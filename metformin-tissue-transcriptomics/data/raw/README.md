# Raw inputs are not vendored

Download the original MILES count table from GEO series GSE107894:
https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE107894

Place the original supplementary file at exactly:

`data/raw/GSE107894_GEO_Kulkarni_et_al_Metformin_counts.txt.gz`

Do not rename or modify its columns. The project deliberately does not redistribute
participant-level raw expression matrices, journal PDFs, or proprietary supplemental tables.
The fibroblast experiment's public record is E-MTAB-16089; this release does not
re-run its upstream count processing.
